# Wee Create

Static storefront for Wee Create, a custom 3D printing studio in the Philippines.

## Publishing and search visibility

The site is configured for GitHub Pages at:

https://wee-ddw.github.io/wee_create/

In the repository settings, enable **Pages** and publish the `main` branch from its root directory. After the site is publicly reachable:

1. Open [Google Search Console](https://search.google.com/search-console).
2. Add `https://wee-ddw.github.io/wee_create/` as a URL-prefix property.
3. Submit `https://wee-ddw.github.io/wee_create/sitemap.xml`.
4. Use URL Inspection to request indexing for the homepage.

Search engines decide when to crawl and list a site, so indexing is not immediate or guaranteed. If a custom domain is used later, update the canonical URL, Open Graph URLs, JSON-LD URLs, `robots.txt`, and `sitemap.xml` to match it.
